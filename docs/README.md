# Domaine InsouWiki

Ce dossier contient les définitions officielles des objets du domaine
utilisés par InsouWiki.

Avant d'implémenter un nouvel objet, une nouvelle fonctionnalité
ou une nouvelle interface, il convient de vérifier si le concept
est déjà défini dans cette documentation.

Les documents de ce dossier constituent la référence du domaine.

Ils répondent à une question simple :

> De quoi parle réellement InsouWiki ?

---

## Principes

Le domaine guide toujours le code.

L'interface guide toujours les priorités.

La source guide toujours la lecture.

---

## Objets documentaires

### Document

Décrit une source documentaire.

---

### Notice documentaire

Présente un document avant sa consultation.

Elle indique :

- le cadre documentaire ;
- les sujets abordés.

Elle ne résume jamais le document.

Elle ne l'interprète jamais.

---

### Enquête documentaire

Met plusieurs documents en relation afin de répondre à une question
du lecteur.

---

### Piste documentaire

Oriente le lecteur vers une source documentaire susceptible
de répondre à son enquête.

---

### Séquence documentaire

Repère un passage précis d'un document.

---

### Fait documentaire

Décrit un fait observable dans un document.

---

### Transcription

Reproduit fidèlement le contenu d'un document.

---

## Évolution du domaine

Tout nouvel objet documentaire doit être documenté dans ce dossier
avant son implémentation.

Cette documentation constitue le vocabulaire officiel d'InsouWiki.

InsouWiki est une plateforme documentaire.

Son objectif est d'aider le lecteur à consulter les sources,
jamais à s'y substituer.

## Méthode de développement

1. Découvrir le concept documentaire.
2. Le définir dans le domaine.
3. L'implémenter.
4. Le tester.
5. Le présenter au lecteur.
