# Revue d'un service

Avant toute modification :

1. Lire le fichier.
2. Identifier sa famille.
3. Identifier sa responsabilité.
4. Identifier les règles métier qu'il applique.
5. Identifier les règles métier qu'il ne doit pas appliquer.
6. Décider si un refactoring est réellement nécessaire.
7. Exécuter les tests.
8. Commit.
