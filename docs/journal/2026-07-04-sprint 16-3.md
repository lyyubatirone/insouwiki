## Sprint 16.3 — Premières relations entre entités documentaires

Ce sprint introduit les premières briques du futur graphe documentaire d'InsouWiki.

Deux nouveaux éléments ont été ajoutés :

* `DocumentaryEntityRelation`, qui relie une entité documentaire source à une entité documentaire cible ;
* `DocumentaryEntityRelationType`, qui définit les premiers types de relations entre entités.

Cette première version reste volontairement minimale. Les dates de validité, les justifications documentaires et les sources associées seront ajoutées lorsque les cas documentaires correspondants auront été stabilisés.

Cette étape marque le passage d'un modèle constitué d'entités isolées à un modèle capable de représenter des liens explicites entre objets du monde documenté.

**Résultat : 59 tests verts.**
