CARTE DU DOMAINE

Pourquoi cette carte ?



Cette carte représente les principaux concepts du domaine documentaire d'InsouWiki ainsi que leurs relations.



Elle ne décrit ni l'architecture logicielle ni les technologies utilisées.



Elle constitue une représentation du métier.



Lorsqu'un nouveau concept apparaît, il doit pouvoir trouver naturellement sa place sur cette carte.



Si ce n'est pas le cas, le domaine n'est probablement pas encore suffisamment compris.

Les grands concepts

Les Sources



Les sources sont les producteurs du patrimoine documentaire.



Exemples :



personnalité politique ;

organisation ;

institution ;

association.



Une source peut disposer de plusieurs points d'entrée.



Les Points d'entrée documentaires



Les points d'entrée sont les canaux officiels par lesquels une source diffuse ses documents.



Exemples :



chaîne YouTube ;

site officiel ;

flux RSS ;

podcast.



Ils constituent les éléments vivants du patrimoine.



Ils sont régulièrement observés.



Les Documents



Les documents sont les productions originales diffusées par une source.



Ils constituent la matière première du patrimoine documentaire.



Ils sont considérés comme immuables après leur publication.



Les Transcriptions



Les transcriptions permettent de transformer un document audiovisuel en contenu textuel exploitable.



Elles servent uniquement à accéder au contenu documentaire.



Les Séquences documentaires



Les séquences documentaires constituent la plus petite unité documentaire consultable.



Chaque séquence est :



horodatée ;

traçable ;

reliée à son document d'origine.



Toute citation repose sur une ou plusieurs séquences documentaires.



Les Connaissances



Les connaissances sont construites à partir des séquences documentaires.



Elles ne remplacent jamais les sources.



Elles permettent d'explorer le patrimoine documentaire.



La Recherche documentaire



La recherche documentaire constitue le point d'entrée du lecteur.



Elle interroge le patrimoine documentaire et renvoie des éléments toujours reliés à leurs sources.



Les opérations



La carte décrit les objets du domaine.



Les actions qui les relient sont décrites dans OPERATIONS-DOCUMENTAIRES.md.



Les quatre grandes familles d'opérations sont :



Observer

Acquérir

Enrichir

Consulter

Les principes



Cette carte est gouvernée par les principes fondateurs d'InsouWiki.



En particulier :



le domaine guide toujours le code ;

l'observation guide toujours le domaine ;

les sources originales demeurent immuables ;

le patrimoine documentaire est constitué de faits observables ;

le lecteur doit toujours pouvoir distinguer les faits, les citations, les synthèses et les interprétations.
