OPÉRATIONS DOCUMENTAIRES

Pourquoi ce document ?



InsouWiki n'est pas construit autour de technologies mais autour d'opérations documentaires.



Avant d'écrire un service ou une fonctionnalité, il est nécessaire d'identifier l'opération documentaire réalisée.



Le domaine guide toujours le code.



Les quatre familles d'opérations documentaires



Toutes les opérations documentaires d'InsouWiki appartiennent à l'une des quatre familles suivantes :



Observer

Acquérir

Enrichir

Consulter



Cette classification permet de distinguer clairement les responsabilités des différents objets du domaine.



1\. Observer



Observer consiste à constater l'état d'un élément du patrimoine documentaire sans le modifier.



Une observation décrit uniquement des faits.



Elle n'interprète jamais ces faits.



Exemples :



observer une source ;

observer un point d'entrée documentaire ;

observer un document ;

observer l'évolution du patrimoine.



L'observation constitue la première étape de toute opération documentaire.



2\. Acquérir



Acquérir consiste à intégrer de nouveaux éléments dans le patrimoine documentaire.



L'acquisition modifie le patrimoine.



Exemples :



découvrir une source ;

découvrir de nouveaux documents ;

indexer un document ;

enregistrer des séquences documentaires.



L'acquisition transforme une ressource extérieure en patrimoine documentaire.



3\. Enrichir



Enrichir consiste à augmenter la valeur documentaire d'un patrimoine déjà existant.



Aucun document nouveau n'est nécessairement créé.



Exemples :



réindexer un document ;

produire une synthèse ;

identifier des thèmes ;

relier des connaissances ;

calculer des représentations vectorielles ;

améliorer des métadonnées.



L'enrichissement ajoute des connaissances sans modifier les sources originales.



4\. Consulter



Consulter consiste à permettre au lecteur ou au documentaliste d'utiliser le patrimoine documentaire.



Exemples :



rechercher ;

lire ;

citer ;

vérifier une affirmation ;

explorer un sujet.



La consultation ne modifie pas le patrimoine.



Elle le rend accessible.



Les responsabilités



Chaque objet documentaire possède son propre vocabulaire.



Une Source



Peut être :



découverte ;

observée ;

synchronisée ;

consultée.

Un Document



Peut être :



découvert ;

indexé ;

réindexé ;

consulté.

Une Séquence documentaire



Peut être :



recherchée ;

lue ;

citée ;

reliée à d'autres séquences.

Le Patrimoine documentaire



Peut être :



observé ;

enrichi ;

administré ;

consulté.

Principe fondamental



Une même opération documentaire ne doit jamais appartenir à plusieurs familles.



Par exemple :



une synchronisation commence par observer ;

elle peut conduire à acquérir de nouveaux documents ;

elle pourra ensuite enrichir le patrimoine ;

enfin, ces nouveaux contenus deviendront consultables.



Chaque étape possède sa responsabilité propre.



Conséquence architecturale



Les services d'InsouWiki doivent refléter les opérations documentaires.



Ils ne sont pas définis par la technologie utilisée mais par leur responsabilité documentaire.



Une évolution technique ne doit jamais modifier les opérations documentaires.



En revanche, une évolution du domaine peut conduire à faire évoluer l'architecture.



Philosophie



Les opérations documentaires décrivent la manière dont InsouWiki interagit avec le patrimoine documentaire.



Elles constituent la grammaire du projet.



Les objets représentent les noms du domaine.



Les opérations représentent ses verbes.



Ensemble, ils permettent de construire un système documentaire cohérent, explicable et durable.
