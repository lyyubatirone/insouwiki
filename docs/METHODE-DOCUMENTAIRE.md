# La méthode documentaire d'InsouWiki

## Pourquoi ce document ?

InsouWiki n'est pas construit à partir de la technologie.

Il est construit à partir du document.

Ce document décrit la méthode suivie pour concevoir, développer et faire évoluer InsouWiki.

Il constitue une référence pour toute personne participant au projet.

---

# Principe fondamental

Avant toute décision technique, une question doit être posée :

> **Que demande le document ?**

La technologie vient ensuite.

Jamais l'inverse.

---

# Les six étapes de la méthode documentaire

## 1. Observer

Observer les documents.

Comprendre leur structure.

Identifier les situations documentaires réelles.

Le document constitue toujours le point de départ.

---

## 2. Dégager un principe documentaire

À partir de plusieurs observations, formuler un principe général.

Un principe documentaire décrit une propriété durable des documents.

Exemple :

> Une objection et sa réponse appartiennent au même raisonnement documentaire.

---

## 3. Décrire un cas documentaire

Transformer ce principe en une situation concrète.

Le cas documentaire constitue la référence fonctionnelle.

Il décrit ce qu'un documentaliste attendrait.

---

## 4. Écrire le test

Le test vérifie que le logiciel respecte le cas documentaire.

Le test ne crée jamais le principe.

Il le traduit.

---

## 5. Implémenter

Le code constitue la traduction du test.

Chaque composant possède une responsabilité unique.

La simplicité est recherchée en permanence.

---

## 6. Justifier les décisions

Toute décision documentaire importante doit pouvoir être expliquée.

InsouWiki privilégie les indices documentaires aux règles arbitraires.

Une décision n'est pas seulement correcte.

Elle doit être compréhensible.

---

# Les indices documentaires

Un indice documentaire est un élément observé dans un document susceptible d'éclairer une décision documentaire.

Un indice ne constitue jamais une preuve à lui seul.

Plusieurs indices convergent pour former une décision.

Cette approche reproduit la démarche d'un documentaliste.

---

# Les responsabilités

Chaque composant documentaire possède une responsabilité unique.

Par exemple :

- le Séquenceur reconnaît les unités de raisonnement ;
- le Tagger facilite l'exploration ;
- l'Extracteur de faits identifie les affirmations documentaires.

Aucun composant ne remplit la responsabilité d'un autre.

---

# Le rôle de l'intelligence artificielle

L'intelligence artificielle n'est jamais la source des principes documentaires.

Les principes sont définis par la méthode documentaire.

L'IA peut assister certaines décisions lorsque les indices documentaires ne permettent pas de conclure avec suffisamment de certitude.

Elle agit comme un conseiller.

Jamais comme l'autorité documentaire.

---

# Notre objectif

InsouWiki n'a pas pour mission de produire une vérité.

Sa mission est de rendre le patrimoine documentaire intelligible, explorable et vérifiable, afin que chacun puisse exercer librement son propre jugement.

# Conclusion

Le patrimoine documentaire constitue le cœur d'InsouWiki.

Les modèles d'intelligence artificielle évolueront.

Les technologies évolueront.

L'architecture évoluera.

La méthode documentaire, elle, demeure.

Parce qu'elle est construite non autour d'une technologie, mais autour d'un devoir de fidélité envers les documents.

L'intelligence artificielle n'est jamais interrogée pour prendre une décision documentaire globale.

Elle peut être consultée pour évaluer un indice documentaire particulier.

La décision finale appartient toujours à la méthode documentaire d'InsouWiki.

Une connaissance documentaire est d'abord écrite pour les humains.

# L'analyse documentaire

Une analyse documentaire est un raisonnement explicable construit
à partir d'observations documentaires.

Elle ne consiste pas à produire directement une décision.

Elle consiste à :

1. observer le document ;
2. identifier les indicateurs documentaires présents ;
3. expliquer les liens entre ces indicateurs ;
4. proposer une conclusion documentaire.

Une analyse documentaire doit toujours pouvoir être expliquée.

Chaque conclusion doit être justifiée par les observations
et les indicateurs documentaires qui la soutiennent.

Une analyse documentaire n'est jamais une boîte noire.

## Rédaction des observations documentaires

Une observation documentaire décrit exclusivement un fait effectivement constaté dans la source.

Elle doit être :

- fidèle à la source ;
- directement vérifiable ;
- indépendante de toute interprétation documentaire.

Une observation ne qualifie pas le document, n'explique pas le raisonnement et ne propose aucune conclusion.

Elle constitue la traduction documentaire des vérifications réellement effectuées par l'analyseur.

## Construction d'une enquête documentaire

Toute enquête documentaire progresse selon les étapes suivantes :

1. Formuler une question documentaire.
2. Constituer des cas canoniques.
3. Identifier des cas frontières.
4. Rechercher des contre-exemples.
5. Formuler des hypothèses.
6. Stabiliser les découvertes.
7. Traduire les découvertes en tests.
8. Implémenter le code.
