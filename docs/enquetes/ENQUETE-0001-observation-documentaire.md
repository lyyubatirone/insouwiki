# ENQUETE-0001 — Observation documentaire

## Question

Qu'est-ce qu'une observation documentaire ?

---

## Contexte

Le terme "observation" est utilisé dans plusieurs méthodes documentaires et dans `DocumentaryAnalysis`.

Il n'a cependant jamais été défini explicitement.

L'objectif de cette enquête est de déterminer ce qui constitue réellement une observation documentaire.

---

## Cas étudiés

| Énoncé | Observation ? | Remarques |
|---------|:------------:|-----------|
| Le même locuteur intervient dans les deux segments. | Oui | Directement vérifiable. |
| Le segment commence par "Passons maintenant". | Oui | Directement vérifiable. |
| Les deux segments sont séparés de trois secondes. | Oui | Mesurable. |
| Le mot "retraite" apparaît cinq fois. | Oui | Comptable. |
| Les deux segments parlent du même sujet. | À déterminer | Nécessite peut-être une interprétation. |
| Continuité dialogique. | Non | Indicateur documentaire. |
| Le raisonnement continue. | Non | Analyse documentaire. |
| Il faut créer une nouvelle séquence. | Non | Décision documentaire. |

---

## Hypothèses

### H-0001

Une observation documentaire est directement vérifiable dans la source.

À confirmer.
