# TAXONOMIE DOCUMENTAIRE

## Objectif

La taxonomie documentaire d'InsouWiki a pour objectif de faciliter l'exploration d'un corpus documentaire sans jamais modifier ni remplacer les sources originales.

Les classifications sont des aides à la navigation.

Elles ne constituent jamais une preuve documentaire.

Les quatre dimensions documentaires

Chaque document peut être décrit selon quatre dimensions complémentaires et indépendantes.

## 1. Les thèmes

Les thèmes répondent à la question :

De quoi parle ce document ?

Un document peut être associé à plusieurs thèmes.

### Exemples :

Retraites
Planification écologique
Immigration
Nucléaire

Les thèmes décrivent le contenu documentaire.

## 2. Le contexte documentaire

Le contexte documentaire répond à la question :

À quelle période historique ou institutionnelle appartient ce document ?

Chaque document possède un contexte documentaire principal.

Un contexte documentaire est toujours défini par une période temporelle.

### Exemples :

Campagne présidentielle 2022
XVIᵉ législature
XVIIᵉ législature
Élections européennes 2024

Le contexte documentaire situe le document dans le temps.

## 3. Le type documentaire

Le type documentaire répond à la question :

Quelle est la nature de cette prise de parole ?

Chaque document possède un type documentaire principal.

### Exemples :

Interview
Débat
Discours
Conférence
Meeting
Conférence de presse
Question au Gouvernement
Commission parlementaire
Audition
Tribune
Communiqué

Le type documentaire décrit la forme du document.

## 4. Le cadre documentaire

Le cadre documentaire répond à la question :

Dans quel cadre cette prise de parole a-t-elle été produite ?

Le cadre documentaire correspond au média, à l'institution, à l'organisation ou à l'événement ayant accueilli ou diffusé la prise de parole.

### Exemples :

France Inter
France Info
Assemblée nationale
Sénat
Université de Lausanne
Institut La Boétie

Le cadre documentaire n'est pas un lieu géographique.

Il décrit le cadre dans lequel le document a été produit ou diffusé.

## Les classifications documentaires

Les classifications documentaires sont des métadonnées.

Elles facilitent la consultation des documents.

Elles ne modifient jamais le contenu documentaire.

Une classification peut être :

fournie explicitement par la source ;
déduite automatiquement ;
validée manuellement ;
non déterminée.

Lorsqu'une classification est inconnue, le document reste consultable.

Un filtre documentaire ne doit jamais masquer un document dont la classification est inconnue.

## Principe fondamental

Les classifications enrichissent la consultation documentaire. Elles ne remplacent jamais la source documentaire.

## Les quatre questions d'InsouWiki

Toute prise de parole peut être décrite en répondant à quatre questions :

Question	Dimension
De quoi parle-t-on ?	Thème
À quelle période appartient ce document ?	Contexte documentaire
Quelle est la nature de cette prise de parole ?	Type documentaire
Dans quel cadre cette prise de parole a-t-elle eu lieu ?	Cadre documentaire

**La taxonomie documentaire n'a pas pour vocation d'interpréter les documents. Elle a pour unique objectif d'aider le lecteur à retrouver, comprendre et vérifier les sources originales.**
