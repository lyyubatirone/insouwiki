# Règles documentaires d'InsouWiki

Ce document rassemble les règles documentaires qui gouvernent le comportement du moteur documentaire d'InsouWiki.

Ces règles ne décrivent ni une implémentation technique, ni une interface utilisateur. Elles expriment les principes documentaires que le logiciel doit respecter, quelles que soient les technologies employées.

Chaque règle doit être :

* objective ;
* explicable ;
* vérifiable ;
* conforme à la charte documentaire du projet.

Ce document est enrichi progressivement au fil de l'évolution du moteur documentaire.
