## Principe

Les classifications documentaires sont des aides à la navigation. Elles ne font pas partie de la source documentaire elle-même.

### Une classification peut être :

explicite (fournie par la source) ;
déduite automatiquement ;
validée manuellement ;
inconnue.

Le système doit toujours distinguer ces situations.

## Objectif

La classification a pour seul but de faciliter la recherche documentaire.

Elle ne doit jamais modifier le contenu du document ni masquer une information pertinente.

## Exhaustivité

Lorsqu'un lecteur applique un filtre documentaire :

les documents correspondant au filtre sont affichés ;
les documents non classifiés restent accessibles ;
seuls les documents dont la classification est incompatible sont exclus.

InsouWiki privilégie toujours l'exhaustivité à une précision artificielle.

## Évolutivité

Les classifications pourront concerner notamment :

les personnalités ;
les contextes documentaires ;
les types de document ;
d'autres catégories documentaires futures.

Toutes suivent les mêmes principes.
