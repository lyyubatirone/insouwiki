# Indices documentaires

## Indice n°1 — Continuité du locuteur

Description :
Le maintien du même locuteur constitue un indice de continuité documentaire.

Limites :
Ce seul indice ne suffit jamais à conclure.

---

## Indice n°2 — Changement explicite de sujet

Description :
Une annonce explicite d'un nouveau sujet constitue un indice fort de rupture documentaire.

Limites :
Une transition peut parfois être progressive.
